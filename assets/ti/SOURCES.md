# Optional TI reference pictures

Reference sources recorded 2026-11-07. TI product photos and screenshots are not distributed with Equal's public source or binaries. Links are provided for identification and comparison; a source link is not a redistribution license. No TI affiliation or endorsement is implied.

The picture guide works without photo files: it shows each model's description, key features and TI source/guidebook link. If you have permission to use local copies, place the optional PNG files below in `assets/ti/` beside the executable, in the working folder, or in a source checkout. Choose **Reload local photos** in the guide after adding or replacing them. Equal reads these files at runtime rather than embedding them in the binary; each file is limited to 8 MB. The local image files are excluded from the public repository and retain their owners' rights.

Product and guidebook links are included in the app's picture guide. Grade ranges overlap: TI describes TI-15 Explorer as grades 3–6 and TI-34 MultiView as middle school; the app uses both as references for its 4–8 group. References do not imply that Equal implements every feature or exact layout of those devices.
