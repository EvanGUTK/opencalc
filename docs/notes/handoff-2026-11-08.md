## What shipped

- **32 physics/chemistry tools**, in addition to the existing 30 math tools. Explicit quantities, units, formulas and assumptions cover mechanics, electricity, thermodynamics, photons, relativity, decay, Avogadro/moles, molar mass, molarity, dilution, pH, gases and other selected problems. Formula parsing is bounded and supports 84 elements. Science forms are session-only: copy a result into notebook notes or a text object to save it.
- **Notebook pages:** multipage ink, eraser, text, lines, rectangles, ellipses, selection/movement, coordinate alternatives, descriptions, paper backgrounds, undo/redo, zoom/pan and escaped SVG export. Horizontal, vertical and reversed lines work without dragging. Storage is bounded to 64 pages, 4,096 objects, 100,000 ink points and the overall 16 MiB notebook envelope.
- **Notebook v2:** explicit v1 migration, full validation before mutation, bounded serialization, saved math/workspace/page content and optional practice data. Private paths, accessibility preferences, AI chats/attachments and runtime jobs are excluded.
- **Optional local recovery:** initially off; ordered background snapshots, latest/previous revisions, explicit Restore/Keep current/Discard, corrupt-copy handling and no overwrite of the original named file when restoring. Drawing defers background snapshot capture. Discard/close cannot recreate the discarded draft.
- **Narrow views:** science inputs stay visible behind `Choose science tool`; notebook controls collapse into `Page tools` so the fitted page remains visible. Wider layouts retain the full controls.
- **Corrections:** native Enter submission/caret/focus, modal input shielding and focus return, repeated dwell, scanning continuity, glossary names/status, shifted calculator keys, sparse graph trace, near-pole analysis, tiny nonzero display, numerical calculus convergence and scale-aware matrix inversion/determinants.
- **Windows distribution:** per-user NSIS installer and portable ZIP, static CRT, strict payload allowlists, per-file manifests, SHA-256 sums, dependency/font/compiler notices and retry-safe uninstall preserving personal files.
- README, screenshots and implementation/validation notes reflect OpenCalc and the new features.

The familiar calculator faces retain their casing, LCD, key geometry, colors and functional legends while omitting manufacturer/model logos and lettering. OpenCalc remains an independent implementation with documented calculator-language and numerical limits.

## Local commands and gotchas

Run from the repository root. This original checkout uses an ignored vendor override and Cargo cache:

```powershell
$env:CARGO_HOME = Join-Path (Get-Location) '.cargo-cache'
$devTarget = Join-Path $env:TEMP 'opencalc-development-target'
cargo fmt --all -- --check
cargo test --locked --offline --target-dir $devTarget
cargo clippy --locked --offline --all-targets --target-dir $devTarget -- -D warnings
python scripts/test-packaging.py
```

Public clones omit the local override and can use ordinary Cargo registry resolution. For the verified Windows release build:

```powershell
$releaseTarget = Join-Path $env:TEMP 'opencalc-release-target'
$env:CARGO_ENCODED_RUSTFLAGS = @(
  '-C', 'target-feature=+crt-static',
  ('--remap-path-prefix=' + (Get-Location).Path + '=.')
) -join [char]31
cargo build --release --locked --offline --target x86_64-pc-windows-msvc --target-dir $releaseTarget
```

That environment variable affects subsequent Cargo commands in the same shell; keep ordinary development commands in a fresh shell or explicitly remove the task-set variable afterward. Use `--data-dir PATH` for isolated native profiles. `--self-test` emits curriculum JSON and exits without loading preferences. Release executables use the Windows GUI subsystem: capture CLI output with explicit process pipes/redirects. The packaging smoke script uses `System.Diagnostics.Process` because PowerShell `Start-Process` followed by a timed wait could lose the exit code of a very fast process.

Installed profiles use `%LOCALAPPDATA%\OpenCalc`. Portable profiles use an adjacent `data` directory selected by `opencalc.portable` or `--portable`; explicit `--data-dir` takes precedence. Never read or commit personal preferences/notebooks.
